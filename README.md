# Danna Te Amo

Esta es una página web simple que muestra "Danna Te Amo" en letras grandes.

## Archivos del proyecto

- `index.html`: El archivo principal de la página web.
- `styles.css`: Archivo CSS para el estilo de la página.
- `script.js`: (Opcional) Archivo JavaScript para efectos adicionales.

## Descripción

La página muestra el texto "Danna Te Amo" en letras grandes, con un estilo atractivo y un pequeño efecto de ampliación al pasar el cursor sobre el texto.

## Cómo ver la página

Puedes ver la página en el siguiente enlace: [https://tu-usuario.github.io/danna-te-amo](https://tu-usuario.github.io/danna-te-amo)
